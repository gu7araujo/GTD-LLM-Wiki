# Andrej Karpathy

_Author of the [[llm-wiki-pattern|LLM Wiki]] pattern — the seed idea this vault implements._

## Overview

Karpathy authored the "LLM Wiki" idea file ([[llm-wiki-pattern-source|source]]) describing a method
for building personal knowledge bases with LLMs. He frames the idea file as something to hand to your
own LLM agent (Claude Code, Codex, OpenCode/Pi, etc.), which then builds the specifics in collaboration
with you.

## Key facts

- Wrote the seed source of this vault, [[llm-wiki-pattern]].
- Describes his own practice: LLM agent on one side, [[obsidian|Obsidian]] on the other, editing the
  wiki live while he browses links and the graph view.
- Coined this vault's guiding metaphor: **Obsidian is the IDE, the LLM is the programmer, the wiki is
  the codebase.**
